# 桌面端雙風格介面：冒險者公會戰情室整合計畫 (Guild View Integration Plan)

本計畫旨在為 `Codex / Antigravity 帳號切換工具` 保留既有架構與管理功能的基礎上，新增一套針對桌面端重新設計的 **RPG 冒險者公會戰情室（Guild Cockpit View）**，並提供一鍵雙向切換機制。

---

## 一、 需求與設計原則

1. **架構完整相容（Non-Breaking Guarantee）**：
   - 既有的 Codex / Antigravity 雙分頁 ListView 傳統管理介面完整保留，現有按鈕、快捷鍵與切換流程不受任何影響。
   - 資料儲存、DPAPI 加密機制、Windows Credential Manager 讀寫與 Quota 查詢核心邏輯完全重用。

2. **桌面專屬公會風格介面（Desktop-Optimized Guild UI）**：
   - 不照抄 Web 版的多欄長頁捲動，改為符合桌面程式（`1150 x 620` 視窗）的**左右雙欄戰情佈局**：
     - **左側【當前出戰英雄】**：放大展示當前登入帳號的像素立繪（精神飽滿／疲憊／耗盡）、方案徽章、5 小時與每週能量條、重置倒數。
     - **右側【後備英雄營地】**：以卡片清單列出其他備用帳號，每張卡片皆顯示剩餘戰力與一鍵**「召喚出戰（立即換號）」**按鈕。
     - **頂部【公會旗艦選單】**：Codex 符文騎士 ⇄ Antigravity 軌道工匠切換，以及右上方的一鍵「📋 傳統清單 ⇄ ⚔️ 公會戰情」切換鈕。
     - **底部【戰情通報列】**：顯示最近同步時間、全體戰力摘要、下次重置倒數。

3. **零外部執行期依賴（Zero External Runtime）**：
   - 使用原生的 WinForms GDI+ 與標準控制項（Panel, PictureBox, ProgressBar, Button）自繪風格外觀。
   - 英雄像素圖檔（精神飽滿、工作執行、疲憊、耗盡）納入 `src/assets/guild/`，建置時自包含於安裝包中，不需要 Python / Node.js 環境。

## 三、 技術實作細節

### 1. 視圖狀態管理 (View State Manager)
- 視窗層級加入 `$script:CurrentViewMode`（預設 `'Classic'` 或 `'Guild'`）。
- 新增持久化使用者偏好（儲存於 `%LOCALAPPDATA%\CodexAccountSwitcher\ui-pref.json`）。
- 點擊「切換視圖」時：
  - 若切換至 Guild：隱藏 `$tabs`，顯示 `$guildPanel`，背景換深色 `#0B1120`，重新自繪。
  - 若切換至 Classic：隱藏 `$guildPanel`，顯示 `$tabs`，背景換回標準 `#F7F8FA`。

### 2. 英雄立繪與姿態映射引擎 (Avatar & Pose Engine)
- 資源位置：`src/assets/guild/{agent}-{pose}.png`。
- 姿態判定公式：
  - `Remaining == 0` 或 `Status == 'HTTP 401'` → `exhausted`（耗盡累癱）。
  - `Remaining <= 20` 或 `Status == 'HTTP 429'` → `tired`（疲憊待補給）。
  - `Remaining > 20` → `energetic`（精神飽滿）。
  - 若未來支援 Antigravity Hook 或進程活躍 → `working`（執行任務中）。

### 3. 公會戰情數據聯動 (Data Binding)
- 當額度查詢計時器觸發 `Update-QuotaResults` 與 `Update-AGQuotaResults` 時，同步更新：
  - 傳統 ListView 欄位。
  - 公會主出戰卡片與備用營地卡片（能量條百分比、重置倒數、立繪更新）。

### 4. 智慧輪替安全控制與來源隔離 (Smart Rotation Rules)
- **來源嚴格隔離（Source-scoped Isolation）**：
  - Codex 符文工會僅能輪替 Codex 帳號庫（替換 `auth.json`）。
  - Antigravity 術士星軌僅能輪替 Antigravity 帳號庫（替換 Windows 認證）。
  - 跨來源嚴格禁止混淆或互換，輪替候選池僅限「當前作用中來源」。
- **單一帳號自動隱藏（Cardinality Threshold Gate）**：
  - 當前來源帳號總數 $\le 1$ 時（無任何可替換後備帳號），「智慧輪替」按鈕強制隱藏（`Visible = False`），不占版面。
- **使用者自主開關選項（User-Configurable Toggle）**：
  - 設定中提供「啟用智慧輪替輔助按鈕」選項（預設關閉或開啟，依偏好持久化）。
  - 當使用者手動關閉時，介面完全隱藏該功能鈕。
- **後備防呆判定**：
  - 當所有後備英雄之 5 小時額度皆為 0% 或處於錯誤狀態時，按鈕自動反灰停用並顯示 Tooltip「無健康後備英雄可供輪替」。

## 五、 驗證與驗收方式

1. **單元與邏輯測試**：執行 `tests/Run-SelfTest.ps1`，驗證姿態映射、視圖切換狀態記憶、以及資源完整性。
2. **GUI 雙視圖預覽產出**：
   - 擴充 `-PreviewPath` 支援生成 `preview-classic.png` 與 `preview-guild.png`。
   - 透過 Antigravity Preview pane 直接檢視繪製出的深色冒險者公會介面。
3. **切換功能驗收**：在公會視圖點擊後備帳號的「召喚出戰」，確認能否正常替換憑證並重啟對應應用程式。
